# Life - 美丽心情

https://unplage.github.io/Life/

本地优先的女性生活记录 PWA。无需注册，数据默认只保存在当前设备。

## 功能模块

- **今日** - 周期/孕周摘要、一秒快记（经期/体重/一句话日记）、全局搜索、未来 7 天提醒、纪念日与健康提示
- **周期** - 经期记录/编辑/删除、周期与排卵期估算（含异常提示）、可翻月日历标注；进入孕期或产后恢复期后自动暂停经期预测
- **孕产** - 备孕/孕期/分娩/月子记录；血压/尿蛋白/症状分级提示、分类血糖与 75g OGTT / 50g GCT、按孕周分层的胎心胎动提示、HCG 48h 变化与 HCG/孕酮趋势图、宫缩 5-1-1 计时；孕前 BMI 与单胎增重参考、孕产档案与产检日程；末次月经（按周期校正）/早孕超声/IVF 预产期计算、妊娠结局登记（入口收于孕期设置）、标准中文 EPDS 10 题筛查与危机指引；产后 42 天复查/EPDS 复测提示、早产儿矫正月龄、产检记录与检查图片
- **宝宝** - 体重/身长/头围曲线与 WHO 2006 官方 LMS 百分位（0–5 岁，按日龄/月龄插值）、国家免疫规划按剂次对照与到期提醒、饭食排泄、宝宝时光相册（自动显示月龄）
- **记录** - 穿搭、衣橱、体重体脂、心情日记、待办事项
- **健康** - 默沙东诊疗手册中文版大众版主题索引、分类浏览、搜索、收藏与阶段相关阅读
- **我的** - 纪念日、数据导入导出、加密备份、通知、应用锁与显示设置

## 数据与隐私

- IndexedDB 本地存储，不上传服务器
- JSON 导入导出，支持换机迁移；导入前自动尝试备份当前数据，导入含字段校验、容量限制与版本迁移
- 照片压缩存储，支持导出还原；所有记录均可编辑；长文本有本地草稿，长列表分页加载
- 可选 6–8 位数字应用锁（PBKDF2 60 万次，旧版 4–6 位密码仍可解锁并自动升级）；离开 5 分钟后再次打开会锁定；连续输错 5 次后指数退避限速；锁定时通知不显示详情
- 可选 AES-GCM 加密备份（`.lifeenc`，兼容旧版 15 万次迭代），密码不会保存；导出后记录时间，超过 30 天未备份会在“我的”页提醒
- 农历生日支持闰月写法（如 `2020-闰4-01`），修正闰月年份换算偏差
- 导入采用单事务原子写入（失败整体回滚），偏好设置随导出迁移；加密备份导入同样执行版本迁移
- 应用锁 PIN 采用恒定时间比较，失败次数同时写入 IndexedDB；6–8 位密码通过掩码输入框设置（不再使用 `prompt`）
- 健康计算采用医学参考：EPDS 使用经翻译验证的标准 10 题与逐题选项分值；血糖按空腹/OGTT 类型区分阈值，75g OGTT 采用 5.1/10.0/8.5 mmol/L、50g GCT 采用 1h 7.8 mmol/L；IVF 预产期按移植日 + 266 天 − 胚胎日龄计算；孕期增重参考中国《孕前和孕期保健指南（2021）》单胎范围；妊娠结局需显式登记，过期妊娠不会自动恢复经期预测。阈值仅作记录提示，不能替代医院报告与医生判断
- 清空数据会同时清理数据库、`life_*` 本地设置和本项目缓存

## 健康信息边界

- `health-links.json` 仅收录默沙东诊疗手册的**标题与官方链接**，由 `tools/build_health_index.py` 生成
- 生长百分位数据由 `tools/build_who_lms.py` 从 WHO 官方 LMS 表生成并内联在 `index.html`；`python3 tools/build_who_lms.py --check index.html` 可校验数据未被改动（需 `openpyxl`）
- 应用不复制、不缓存、不内嵌 MSD 文章正文、图片或视频，不使用 MSD 标识
- 所有健康内容仅用于信息导航，不能替代专业医疗建议、诊断或治疗
- 本站为个人非商业项目，与默沙东/MSD 无隶属或合作关系
- `health.js` 支持本地索引缓存、分类/搜索/收藏、阶段相关阅读和官方站内搜索兜底

## PWA 特性

- Service Worker 离线缓存，无网络也能使用核心功能
- ECharts 按需懒加载（仅进入体重/孕产图表时加载，不阻塞首屏）
- 健康索引采用 stale-while-revalidate；不缓存跨域 MSD 文章
- 可添加到主屏幕，支持经期/心情/健康快捷方式
- 自动检测新版本，提示刷新更新
- 项目作用域缓存，避免与同一 GitHub Pages 域下其他 PWA 冲突

## 开发与测试

```bash
npm install
npm test                # jsdom + fake-indexeddb 集成测试
npm run test:health     # 校验 health-links.json
python3 tools/build_who_lms.py --check index.html  # 校验 WHO LMS 数据（需 openpyxl）
python3 tools/check_health_links.py --online   # 可选：联网探测链接
```

## 技术栈

- 纯前端单文件应用（HTML + CSS + JS）
- IndexedDB 存储
- ECharts 图表（延迟加载）
- Service Worker + Cache API 离线方案
- Web Crypto（PBKDF2 + AES-GCM）
- 农历转换算法
