# Life - 美丽心情

https://unplage.github.io/Life/

生活记录 PWA 应用，支持离线使用。

## 功能模块

- **穿搭管理** - 温度穿搭建议、衣橱分类管理、穿搭照片记录
- **体重体脂** - 体重/体脂率记录、趋势图表
- **生理期记录** - 周期追踪、日历标注、排卵预测、症状记录
- **孕期全周期** - 备孕/怀孕/分娩/月子/宝宝成长全阶段记录
- **心情日记** - 心情选择、日记撰写与浏览
- **纪念日提醒** - 农历生日转换、相识/订婚/结婚纪念日倒计时、浏览器通知提醒

## 数据管理

- IndexedDB 本地存储，所有数据留在设备上
- JSON 导入导出，支持换机迁移
- 照片压缩存储，支持导出还原

## PWA 特性

- Service Worker 离线缓存，无网络也能使用
- 可添加到主屏幕，像原生 App 一样使用
- 自动检测新版本，提示刷新更新

## 技术栈

- 纯前端单文件应用（HTML + CSS + JS）
- IndexedDB 存储
- ECharts 图表
- Service Worker + Cache API 离线方案
- 农历转换算法
